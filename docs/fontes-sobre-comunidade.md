# Fontes do texto “Sobre a comunidade”

O contador do perfil indicava 25 mídias; a página seguinte da API veio vazia, portanto este levantamento **não é um inventário completo**. Não inferir a data de fundação, a periodicidade de encontros ou a realização de eventos apenas anunciados.
